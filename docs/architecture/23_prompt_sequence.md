# SecStorage — 23-Prompt Implementation Sequence Roadmap

This map defines the 23 controlled implementation prompts grouped into 7 development waves:

## Wave 1: Core Foundation & API Design
- `01`: Master Architect & Execution Controller (Current Stage)
- `02`: Requirements, Scope & MVP Contract
- `03`: Full-Stack Architecture & System Design
- `04`: GitHub Monorepo & Engineering Foundation
- `05`: FastAPI Backend Foundation
- `06`: PostgreSQL + SQLAlchemy 2.x + Alembic Integration
- `07`: REST + JSON + Pydantic v2 + OpenAPI Contracts

## Wave 2: Identity, Auth & RBAC
- `08`: Authentication + JWT + Refresh Cookies + Argon2id
- `09`: Authorization + Server-Side RBAC (Owner, Editor, Viewer)

## Wave 3: Core Domain Services
- `10`: Object Storage Abstraction & Presigned Upload/Download URLs
- `11`: Files, Folders & Parent-Child Hierarchy Management
- `12`: Search Engine, Starred Resources & Soft-Delete Trash System
- `13`: User Sharing & Expirable Password-Protected Public Links
- `14`: Activity Auditing, Versioning & Media/PDF Previews

## Wave 4: Backend Audit & Testing
- `15`: Pytest Suite, Security Audit & Performance Tuning

## Wave 5: Modern React Frontend
- `16`: React + TypeScript + Vite + Tailwind Scaffolding
- `17`: Authentication & Session Management UI
- `18`: Workspace Dashboard & Interactive File Explorer
- `19`: File Actions, Presigned Upload/Download & Media Preview Components
- `20`: User Sharing, Starred, Search & Trash UI Views

## Wave 6: Integration & Quality Assurance
- `21`: Full-Stack Integration, E2E Testing & Production Hardening

## Wave 7: Deployment & Release
- `22`: Render (`render.yaml`) & Vercel Deployment Setup
- `23`: Final Production Audit, Documentation & Release Package
